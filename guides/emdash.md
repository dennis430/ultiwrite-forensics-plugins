# EmDash integration

Integration preparation uses the same product-owned connection profile and remote OAuth endpoint `https://mcp.ultiwrite.co/mcp`. Consult the current official EmDash MCP documentation at https://emdash.ai/docs/library/mcp for its custom-server settings and per-agent synchronization. In Library → MCP → Custom MCP, supply the product name, HTTP transport and endpoint, then choose Sync to agents. For a remote machine, use Settings → Machines → the intended machine → MCP; paths and local services resolve on that actual machine. EmDash writes native agent configuration and may disable targets without HTTP support. Its documented custom-server fields do not establish an EmDash OAuth callback: authenticate each supported target agent through its own native OAuth flow with your Forensics account. Do not place a shared REST API key in optional headers to bypass consent or invent an EmDash plugin manifest. No EmDash catalog submission route is established.

Verify `ultiwrite_forensics_account_get` and `ultiwrite_forensics_capabilities_get` before intake, then follow REVIEWER-GUIDE.md for synthetic file access, browser handoff, stable retries, separate PDF retrieval and tenant denial. A configured server or successful sync does not prove a full examination journey or directory acceptance. Record the installed EmDash version and actual OAuth result; native EmDash proof remains pending.

No permanent document retention: Your files are processed temporarily for your forensic analysis and automatically deleted. Originals are kept for at most one hour and reports for up to 24 hours. We keep no permanent archive of customer documents or reports; account and billing records are separate. Source files are deleted after processing, at the latest one hour after upload. Reports stay available for download for up to 24 hours, then they are deleted.
