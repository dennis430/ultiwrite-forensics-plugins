# ReadMe documentation integration

This is a documentation-host integration guide, not a plugin registration or upload format. In the standalone ReadMe project, use title **Ultiwrite Forensics**, website https://ultiwrite.co, API specification https://ultiwrite.co/openapi.json and MCP endpoint https://mcp.ultiwrite.co/mcp. Publish the setup guide from https://ultiwrite.co/docs/mcp. Keep any flagship ReadMe project and its API credentials separate. No ReadMe project ownership or publication has been verified.

No permanent document retention: Your files are processed temporarily for your forensic analysis and automatically deleted. Originals are kept for at most one hour and reports for up to 24 hours. We keep no permanent archive of customer documents or reports; account and billing records are separate. Source files are deleted after processing, at the latest one hour after upload. Reports stay available for download for up to 24 hours, then they are deleted.
