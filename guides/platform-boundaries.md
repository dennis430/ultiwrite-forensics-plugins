# Distribution and submission boundaries

Prepared November 11, 2026 UTC. Publisher: DWS Offshore Fund. Owner: Dennis Liu, dennisl@ultiwrite.co. These are source/install artifacts; no marketplace submission or public release is claimed.

- OpenAI portable core: root plugin.json + mcp.json + skills/ + assets/. Codex compatibility metadata is a separate fallback, never merged into inline OpenAI metadata. `openai-portal` retains remote `mcp.json` for the **With MCP** submission route and excludes app references and lifecycle hooks. The portal reads OAuth settings from this file; Skills only is a separate route. Successful local checks do not establish domain proof, a current portal tool/skill scan, a reviewer account or a genuine demo recording.
- Claude: remote connector submission and GitHub plugin submission are separate. Claude Code marketplace installation does not establish OAuth examination from a real Claude conversation or Claude web/mobile support.
- Cursor: repository-native `.cursor-plugin/plugin.json`, root `mcp.json`, relative logo and skills. Submit to the official Cursor Marketplace, not an independent directory. No host variable declarations are needed because this OAuth remote configuration contains no variable interpolation.
- Grok Bot: https://x.ai/bot/marketplace/submit-a-plugin currently covers Grok Bot and Cursor; consumer Grok is marked coming soon. Do not claim a native-tested checkbox before actual in-app proof or submit duplicates across that shared route.
- Grok Build: separate GitHub marketplace contribution. The included contribution pin is a reachable existing public source, package 1.0.4. The prepared new native package is a separate artifact; update the public SHA only after an authorized reviewed public update. The official guide flags branded sources in personal accounts; Dennis owns the brand proof/organization decision.
- Gemini CLI and VS Code/GitHub Copilot are custom installation targets; CLI/configuration does not imply consumer-app support, gallery acceptance or Microsoft 365 acceptance.
- Microsoft 365 uses app-manifest `agentConnectors` 1.30 in this package. The explicit REPLACE_WITH marker is an unresolved portal-issued DCR reference, never a real ID. This track remains blocked until that genuine reference and tenant proof exist.
- Official MCP Registry requires independent proof of `ultiwrite.co` namespace control. Proposed npm ownership is unverified; no npm shim is required.
- Dash and Chester: NEEDS_PLATFORM_IDENTITY. No package is fabricated. Syv Dash and dashAI are different products and neither establishes Dennis's intended client. No official Chester specification has been established.
- AWS Marketplace, Salesforce AgentExchange, Google Connected Apps and Meta/Muse require actual program/packaging/seller prerequisites before implementation. An MCP ZIP is not a cloud SaaS marketplace offer. No partner enrollment or integration claim is made.

Never include reviewer passwords, private engine code, account data, raw customer material or internal security receipts in public packages. All examinations use the connected tenant's own Forensics entitlement ledger. Polling and retrieval are non-billable. Supported transport and live capabilities decide file access; a sandbox filename or attachment ID is not proof of backend access.

No permanent document retention: Your files are processed temporarily for your forensic analysis and automatically deleted. Originals are kept for at most one hour and reports for up to 24 hours. We keep no permanent archive of customer documents or reports; account and billing records are separate. Source files are deleted after processing, at the latest one hour after upload. Reports stay available for download for up to 24 hours, then they are deleted.
